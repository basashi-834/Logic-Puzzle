# 論理回路パズル（Logic Puzzle）

論理演算・論理回路を **ドラッグ＆ドロップで組み立てて、その場で結果を確かめながら** 学べる
ブラウザ用の学習パズルです。ビルド不要・ライブラリ不要。`index.html` を開くだけで動きます。

> 回路を 1 本つなぎ替えるたびに、**真理値表**・**ベン図**・**論理式**が自動で作り直されます。
> 「式 ↔ 回路 ↔ 表 ↔ 図」の 4 つの表現が、いつも同時に見える状態で学べるのが狙いです。

---

## 4 つのモード

| モード | 内容 |
| --- | --- |
| 🧩 **パズル** | 全 18 ステージ。示された真理値表・ベン図と同じはたらきの回路を組み立てます。判定は自動、ヒントと「学びのポイント」つき。 |
| 🛠 **じゆう工作** | 自由に回路を組むサンドボックス。入力スイッチ・出力ランプも増やせ、真理値表／ベン図／論理式（回路どおりの式と主加法標準形）がリアルタイムで出ます。 |
| 📖 **早見表** | AND・OR・NOT・NAND・NOR・EX-OR・EX-NOR の 名称／論理式／MIL 記号／JIS 記号／真理値表／ベン図 の対応表。ブール代数の基本法則表つき。 |
| ❓ **クイズ** | 「記号 → 名称」「記号 → 真理値表」「真理値表 → ゲート」「ベン図 → 論理式」「論理式 → ベン図」の 4 択 10 問。 |

## ステージ構成（全 18 面）

| 章 | ステージ | ねらい |
| --- | --- | --- |
| 第1章 きほんのゲート | 1 AND / 2 OR / 3 NOT | 配線操作と基本 3 演算 |
| 第2章 組み合わせる | 4 NAND / 5 NOR | ゲートの直列接続とバブル（否定）の意味 |
| 第3章 ド・モルガンの法則 | 6 `A·B` の否定 / 7 `A+B` の否定 | AND と OR が NOT で入れ替わること |
| 第4章 EX-OR に挑戦 | 8 EX-OR / 9 EX-NOR | 加法標準形での組み立て |
| 第5章 ベン図パズル | 10 差集合 / 11 含意 | ベン図の塗り分けから論理式を起こす |
| 第6章 NAND は万能 | 12 NOT / 13 AND / 14 OR / 15 EX-OR | 機能的完全性（NAND だけで全部作れる） |
| 第7章 実用回路 | 16 多数決回路 / 17 半加算器 / 18 全加算器 | 3 入力・複数出力の実用回路 |

各ステージには「最小ゲート数」の目安があり、達成すると ★ が表示されます。
クリア状況と組みかけの回路は `localStorage` に自動保存されます。

## 操作方法

| やりたいこと | 操作 |
| --- | --- |
| 部品を置く | パレットから盤面へ**ドラッグ＆ドロップ**（クリックだけでも空き場所に配置） |
| 線をつなぐ | 部品の丸い端子から相手の端子へ**ドラッグ**。出力（右）と入力（左）だけがつながり、1 つの出力から何本にも**分岐**できます |
| 値を変える | 入力ブロックの `0` / `1` の四角を**クリック**。線とランプの色が即座に変わります |
| 部品を消す | **ごみ箱へドラッグ** / **ダブルクリック** / **右クリック** / 選択して `Delete` |
| 線を消す | 線を**クリックして選択 → `Delete`** / **右クリック** / つながっている入力端子をクリック |
| 記号を切り替え | ヘッダー右上の **MIL / JIS** |

## 動作環境

- Chrome / Edge / Firefox / Safari の最近のバージョン（Pointer Events と `<canvas>` を使用）
- インターネット接続・ビルド・サーバ不要。`index.html` をダブルクリックで起動できます
- マウス操作を前提にした画面構成のため、PC・タブレットでの利用を推奨します

### 内部のしくみ

- **評価**：出力側から入力側へ再帰的にたどるメモ化つき深さ優先探索。未接続は「値なし（`-`）」、
  配線が一周した場合はループとして検出し警告します。
- **真理値表**：入力の全組み合わせ（2ⁿ 通り）について回路を評価します。行番号 *i* の *k* 番目の
  ビットは `(i >> (n-1-k)) & 1`。先頭の入力名が最上位ビットです。
- **ベン図**：画素ごとに「どの円の内側か」を判定して領域番号を求め、その領域の出力が 1 なら
  塗ります。この方式のため 1〜3 変数のどんな塗り分けにも対応できます。
- **論理式**：回路構造をそのまま展開した式と、真理値表から求めた主加法標準形の 2 通りを表示します。

## 拡張のヒント

- ステージを増やす → `js/puzzles.js` に 1 件追加するだけ（目標は真理値表のビット列で指定）
- ゲートを増やす（バッファ、3 入力 AND など） → `js/gates.js` に定義を足し、`js/symbols.js` に形状を追加
